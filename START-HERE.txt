ROKU REMOTE 3DS - START HERE

1. Your 3DS needs Homebrew Launcher already installed.
2. Turn off the 3DS. Copy the included 3ds folder to the SD card.
3. Open Homebrew Launcher, then Roku Remote 3DS, Or launch from Home-screen.
4. On your Roku, enable Settings > System > Advanced system settings >
   Control by mobile apps, when that option is available.
5. Find the Roku IP at Settings > Network > About.
6. In the 3DS app, choose Enter Roku IP, then Test connection.
7. Choose Back to remote and try Home.

Both devices must be on the same home network. No computer server is needed.
Roku may restrict third-party control; a successful device check does not
prove button commands are enabled.

D-pad = Move | A = OK | B = Back | X = Home | Y = Play/Pause
L/R = Volume when supported | SELECT = Setup | START = Exit

This is a .3dsx app for Homebrew Launcher, not a HOME Menu CIA.
Build and simulated Roku tests passed. Physical hardware is untested.
See README.md for troubleshooting, source references, and rebuilding.
